# PROMOBET

Site institucional demonstrativo da PROMOBET.

## Publicação estática
O projeto é uma página estática e pode ser hospedado em qualquer serviço de static hosting. O arquivo de entrada é `index.html`.

## Limites desta versão
Esta versão é somente uma demonstração visual. Não implementa autenticação real, carteira, pagamentos, depósitos, saques, prêmios ou apostas. Não conectar provedores de jogos nem serviços financeiros sem as autorizações e controles aplicáveis.

## Domínio
O domínio personalizado deve ser configurado no provedor de hospedagem e no DNS após a publicação.
